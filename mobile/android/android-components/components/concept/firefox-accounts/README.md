# [android-components](../../../README.md) > Concept > Firefox Accounts

This component provides a home for Firefox Accounts API contracts in Android Components.

## Usage

Add the component to your Gradle dependencies:

```groovy
implementation "org.mozilla.components:concept-firefox-accounts:{latest-version}"
```
