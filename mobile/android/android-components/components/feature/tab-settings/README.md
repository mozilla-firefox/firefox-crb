# [Android Components](../../../README.md) > Feature > Tab Settings

A component for persisting tab-related user settings.

`TabSettingsRepository` is the entry point through which consumers observe and update these settings.

### Setting up the dependency

Use Gradle to download the library from [maven.mozilla.org](https://maven.mozilla.org/) ([Setup repository](../../../README.md#maven-repository)):

```Groovy
implementation "org.mozilla.components:feature-tab-settings:{latest-version}"
```
